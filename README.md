# 🚀 Actividades del Taller Paso a Paso

Aquí llevaremos el registro de nuestro avance en cada sesión. Si te pierdes en algún momento, revisa en qué paso vamos y apóyate con tu equipo.

## 🛠️ Clase 1: Entorno de Trabajo y Diseño UI
- [ ] **Paso 1:** Presentación del proyecto final (¿Qué vamos a construir?).
- [ ] **Paso 2:** Verificación de herramientas (Terminal, Node, Composer, Git, Laragon/XAMPP).
- [ ] **Paso 3:** Ingresar al equipo de trabajo en Figma.
- [ ] **Paso 4:** Dinámica: "Figma Party". Diseñar en conjunto el wireframe (Header, Body, Footer).
- [ ] **Paso 5:** Exportar los colores y tipografías usando el *Dev Mode* de Figma.

## 🐙 Clase 2: Primer Código y Control de Versiones
- [ ] **Paso 1:** Crear la carpeta del proyecto en el servidor local (`htdocs` o `www`).
- [ ] **Paso 2:** Abrir la carpeta en Visual Studio Code.
- [ ] **Paso 3:** Inicializar Git en la terminal (`git init`).
- [ ] **Paso 4:** Conectar el repositorio local con GitHub (`git remote add origin...`).
- [ ] **Paso 5:** Crear la estructura base: `index.html` y `style.css`.
- [ ] **Paso 6:** Traducir el diseño de Figma a código HTML/CSS.
- [ ] **Paso 7:** Guardar progreso en la nube (`git add .`, `git commit -m "Estructura inicial"`, `git push`).

## 📦 Clase 3: Motores de Dependencias (Node y Composer)
- [ ] **Paso 1:** Descargar actualizaciones del equipo (`git pull`).
- [ ] **Paso 2:** Inicializar el proyecto en Node (`npm init -y`).
- [ ] **Paso 3:** Instalar alguna utilidad de frontend vía NPM (ej. Bootstrap o Tailwind).
- [ ] **Paso 4:** Inicializar el proyecto en PHP (`composer init`).
- [ ] **Paso 5:** Renombrar nuestro `index.html` a `index.php`.
- [ ] **Paso 6:** Hacer *Commit* de los archivos `package.json` y `composer.json`.

## 🗄️ Clase 4: Base de Datos y Backend (PHP)
- [ ] **Paso 1:** Abrir Laragon/XAMPP y encender MySQL y Apache.
- [ ] **Paso 2:** Crear la base de datos en el gestor (ej. phpMyAdmin o HeidiSQL).
- [ ] **Paso 3:** Crear el archivo de conexión segura `conexion.php` usando PDO.
- [ ] **Paso 4:** Maquetar un formulario de registro en nuestra página principal.
- [ ] **Paso 5:** Escribir la lógica en PHP para capturar los datos del formulario (POST).
- [ ] **Paso 6:** Insertar los datos de prueba en la base de datos SQL.
- [ ] **Paso 7:** Subir cambios a GitHub (`git push`).

## ⚔️ Clase 5: Simulacro de Agencia (Flujo de Trabajo Real)
- [ ] **Paso 1:** Asignación de tareas (*Issues*) en el tablero Kanban de GitHub Projects.
- [ ] **Paso 2:** Dinámica "Caos Controlado": Forzar un *Merge Conflict* en Git modificando la misma línea de código.
- [ ] **Paso 3:** Resolver el conflicto en VS Code trabajando en parejas.
- [ ] **Paso 4:** Limpieza de código final y revisión de responsividad (Chrome DevTools).
- [ ] **Paso 5:** Presentación final del proyecto corriendo en el servidor local.
