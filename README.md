## 🛠️ Clase 2: Entorno de Trabajo y Diseño UI
- [ ] **Paso 1:** Presentación del proyecto final (¿Qué vamos a construir?).

- [ ] **Paso 3:** Exploración de la plantilla de Figma e introducción al *Dev Mode*.
- [ ] **Paso 4:** Extraer assets (ilustraciones) y variables de diseño (colores, tipografías).

- [ ] **Paso 9:** Maquetar el esqueleto HTML semántico de las secciones: Hero (Inicio), About (Sobre mí), Projects (Proyectos) y Contact (Contacto).

- [ ] **Paso 1:** Descargar actualizaciones del equipo (`git pull`).

- [ ] **Paso 3:** Instalar alguna utilidad de frontend vía NPM (ej. Bootstrap o Tailwind).

- [ ] **Paso 3:** Crear el archivo de conexión segura `conexion.php` usando PDO.
- [ ] **Paso 4:** Maquetar un formulario de registro en nuestra página principal.
- [ ] **Paso 5:** Escribir la lógica en PHP para capturar los datos del formulario (POST).
- [ ] **Paso 6:** Insertar los datos de prueba en la base de datos SQL.
- [ ] **Paso 7:** Subir cambios a GitHub (`git push`).

- [ ] **Paso 4:** Limpieza de código final y revisión de responsividad (Chrome DevTools).
